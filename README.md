## WAJIB DIBACA OLEH SEMUA AI / KONTRIBUTOR

Sebelum membaca task atau mengubah file, baca **[AI-WORK-RULES.md](./AI-WORK-RULES.md)**.

**PENTING: Activity Book / PDF Belajar Wudhu sesuai Sunnah sudah SELESAI dan FINAL. Tidak ada program pengerjaan lanjutan, revisi, audit, perapian, desain ulang, atau pembuatan versi baru.** Master PDF final sudah disimpan pemilik di perangkat lokal dan tidak perlu disimpan di GitHub.

**PENGECUALIAN YANG WAJIB DILINDUNGI:** audio dzikir setelah wudhu tetap diperlukan oleh PDF final. Jangan mengubah, menghapus, memindahkan, mengganti nama, atau memutus halaman pemutar maupun file/aset audio yang mendukung URL berikut:
https://khusnajulidar.github.io/pnata-digital-projects/activity-book-wudhu/audio/dzikir-setelah-wudhu/

Tidak ada pekerjaan baru untuk PDF. Mempertahankan audio dan tautannya adalah kewajiban perlindungan aset, bukan task pengembangan.

Sebelum memulai pekerjaan lain, periksa branch, commit, file yang sedang berubah, dan task agent lain untuk mencegah pekerjaan ganda. Satu task hanya memiliki satu agent pelaksana utama. Jangan menimpa perubahan agent lain.

## Standar lintas proyek

Pedoman utama untuk desain mockup dan implementasi UI seluruh game P'Nata Digital, termasuk proyek berikutnya, tercatat di [STANDAR-DESAIN-IMPLEMENTASI-GAME.md](./STANDAR-DESAIN-IMPLEMENTASI-GAME.md).

Inti pedoman: mockup menjadi template visual berkualitas tinggi; ilustrasi dan identitas visual dipertahankan, sedangkan judul, konten, pilihan, tombol, status, dan interaksi dibuat dinamis sesuai kebutuhan. Penggunaan UI dinamis wajib menjaga kualitas tampilan agar tidak menurun dibanding mockup asli.
