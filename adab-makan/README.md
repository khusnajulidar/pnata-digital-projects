# Proyek Game Adab Makan

Repository kerja proyek game edukasi interaktif P'Nata tentang adab makan untuk anak usia 3–4 tahun.

## Standar desain dan implementasi mockup

Pedoman terbaru untuk semua proyek P'Nata Digital tercatat di [../STANDAR-DESAIN-IMPLEMENTASI-GAME.md](../STANDAR-DESAIN-IMPLEMENTASI-GAME.md). Mockup diperlakukan sebagai template visual; elemen konten dan interaksi yang perlu berubah dibuat dinamis. Kualitas tampilan hasil implementasi wajib tetap setara dengan mockup asli.

Catatan pendekatan integrasi yang lama di [MOCKUP-INTEGRATION-DECISIONS.md](./MOCKUP-INTEGRATION-DECISIONS.md) telah ditandai sebagai **digantikan**. Jangan mengikuti larangan UI dinamis dalam catatan lama sebagai aturan aktif. Ketentuan khusus Peta Lima Misi dan keputusan proyek lain yang tidak bertentangan tetap berlaku.
