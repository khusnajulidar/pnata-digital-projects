## 3. PROTOKOL WAJIB ANTI-PEKERJAAN GANDA

Sebelum melakukan perubahan apa pun:
1. Baca README.md dan dokumen ini sampai selesai.
2. Periksa commit terbaru, branch aktif, file yang berubah, dan Pull Request yang terbuka.
3. Cari apakah pekerjaan yang sama sudah sedang dikerjakan oleh akun/agent lain.
4. Jangan mengasumsikan bahwa branch bernama `main` adalah satu-satunya sumber perubahan terbaru.
5. Jangan mengedit file atau area kerja yang sedang ditangani agent lain tanpa koordinasi dan persetujuan pemilik.
6. Jika status pekerjaan atau pemilik tugas tidak jelas, berhenti dan minta konfirmasi pemilik sebelum mengubah file.
7. Satu pekerjaan hanya boleh memiliki satu agent pelaksana utama. Agent lain berperan sebagai reviewer hanya jika diminta.

## 4. ATURAN PERUBAHAN GITHUB

- Jangan menghapus, menimpa, me-rollback, atau memindahkan file yang sedang dikerjakan agent lain.
- Jangan melakukan force-push atau mengubah riwayat commit.
- Jangan menganggap file yang tidak terlihat pada branch saat ini berarti file itu tidak ada di branch lain.
- Gunakan branch terpisah untuk pekerjaan baru; jelaskan tujuan branch dan file yang akan diubah.
- Sebelum merge, periksa diff dan pastikan tidak ada perubahan pekerjaan lain yang ikut tertimpa.
- Catat setiap pekerjaan baru dengan status, agent pelaksana, ruang lingkup file, dan hasil terakhir.
- Jika dua agent ternyata mengerjakan tugas yang sama, hentikan salah satunya sebelum perubahan lebih lanjut dan koordinasikan penggabungan hasil.
