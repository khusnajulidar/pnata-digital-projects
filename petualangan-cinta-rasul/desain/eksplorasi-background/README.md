# Eksplorasi Background — Mockup 01

Folder ini menyimpan seluruh kandidat dan percobaan background Gemini untuk **Mockup 01 — Halaman Pembuka** game *Petualangan Cinta Rasul*.

## Penamaan file

Gunakan nama berurutan agar setiap percobaan mudah dilacak:

- `mockup-01-background-kandidat-a.png` — gambar awal
- `mockup-01-background-kandidat-b.png` — alternatif miniatur diorama
- `mockup-01-background-kandidat-c.png` — alternatif storybook
- `mockup-01-background-kandidat-d.png` — hasil eksplorasi terbaru

Jika format gambar berbeda, sesuaikan ekstensi file (misalnya `.jpg` atau `.webp`). Jangan menimpa kandidat sebelumnya.

## Catatan

Semua file di folder ini berstatus **eksplorasi**, belum menjadi aset final. Background terpilih baru akan ditetapkan sebagai aset final setelah evaluasi dan persetujuan.
